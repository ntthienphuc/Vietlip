# VietLip 1.6.0 — bộ cài Android và Windows

Tên người dùng chọn: **VietLip**. Giữ application ID và chứng thư ký Android
để cập nhật app hiện có và giữ lịch sử. APK được build ở chế độ release.

## Thay đổi

- Nhận diện mới, biểu tượng mới, nền sáng và xanh ngọc, header gọn.
- Preview dùng tỷ lệ thật; phụ đề có khung riêng với trạng thái và chữ lớn.
- Luồng sử dụng là **Wi-Fi / LAN nội bộ**. Server hiện IP, cho chọn địa chỉ khi
  có nhiều interface, sao chép IP và làm mới khi đổi mạng.
- Android nhận IP thuần, IP:cổng hoặc URL; mặc định cổng 7100. Bỏ địa chỉ
  loopback/emulator của bản thử trước khi nâng cấp và hướng dẫn nhập IP thật.
- Kiểm tra server có thời hạn chờ; trạng thái ready phụ thuộc model và warmup.
- Sửa đường dẫn model mặc định từ config để checkout/bộ cài mới không vô tình
  tìm trong `server/server`. Bộ cài ép cấu hình production, bỏ các biến môi
  trường thử nghiệm và không cần LLM/API key.
- Bộ cài gồm Python 3.11, runtime CPU/CUDA, SO17 và license. Không kèm video,
  khóa ký, dataset hoặc các checkpoint thử nghiệm khác.
- Gom 30 bản xuất cũ vào `output/archive/pre_vietlip_1_6`; kiểm hash trước/sau
  khi chuyển. Script installer cũ chuyển vào `packaging/legacy_windows_server_1_1`.

## Giới hạn mạng tại lúc thử

Trên mạng khách đang dùng, PC và điện thoại cùng dải IP nhưng TCP từ điện thoại
đến server bị timeout. Đã gỡ ADB reverse trước phép thử; không dùng USB làm
đường suy luận. App báo lỗi kết nối và trả quyền thao tác thay vì chờ mãi.

Chưa coi phép thử này là chứng minh live Wi-Fi thành công. Cần mạng riêng cho
phép thiết bị liên lạc nhau để kiểm tra đường camera → server → phụ đề thực tế.
Kết quả loopback của PC không thay thế phép đo này.
Người dùng đã chọn hoàn thiện bộ cài trước và sẽ thử ở mạng khác sau.

Không đổi mô hình nhận dạng trong đợt đóng gói. Độ chính xác nói tự do vẫn còn
hạn chế; không suy ra UI đẹp hơn hoặc bộ cài đầy đủ làm giảm WER.

Evidence chi tiết và các biên nhận bộ cài nằm tại `artifacts/vietlip_160`.
Kết quả cuối cùng của gói cài được ghi trong `DELIVERY_RECEIPT.json` và bản
`03-Huong-dan/KIEM_THU.md` đi cùng thư mục bàn giao.
Thư mục bàn giao có `CHECKSUMS-SHA256.txt` để kiểm tra APK, Setup và hai file
`.bin`; cần giữ cả ba file server cạnh nhau khi chạy cài đặt.
